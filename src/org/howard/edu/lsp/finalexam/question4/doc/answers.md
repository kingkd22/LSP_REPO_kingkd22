# Question 4 Answers

Coming into this semester I mostly used AI as a way to get quick answers when I was stuck, kind of like a faster search engine. After actually using it throughout the assignments I realized it is more useful as a collaborator than an answer machine. When I asked it to help me understand the Strategy pattern for assignment 3, it did not just give me the code, it explained why you would reach for that pattern over something like a bunch of if-else chains. That changed how I thought about it. The thing I also noticed is that when you use AI without really reading what it gives you, you end up with code that compiles but that you cannot explain. I got tripped up once doing that early in the semester and it cost me time when I had to debug it.

Going forward I plan to use AI as a tool for getting unstuck and for checking my reasoning, not for writing the code for me. For example if I am working on a design and I cannot decide between two patterns, I would use it to talk through the tradeoffs. I also want to use it more for test generation ideas since coming up with boundary cases on my own is something I still find tedious. The main thing I want to stay consistent on is making sure I understand whatever it produces before I use it.
